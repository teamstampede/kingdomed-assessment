Step-by-Step Setup
1
Create the master client vault in Google Drive
drive.google.com → New → Folder → Name: KingdomED Consulting — Clients. This is the top-level vault for all client files.
2
Create the Templates subfolder
Inside the master folder, create _KingdomED_Templates (underscore keeps it sorted to the top). Upload the Companion Document here as the master copy to duplicate for each new client.
3
For each new client — duplicate the template folder
Right-click _KingdomED_Templates → Make a copy → Rename to the client’s school name and city. Same clean structure every time, zero setup from scratch.
4
Set up the Google Form for client submissions
forms.google.com → New Form → Title: KingdomED Client Assessment Submission. Fields: School Name, Contact, Email, File Upload (for 3–5 year plan). Link responses to a Google Sheet that auto-saves to your vault.
5
Share the client folder with Dr. Otero each session
In your Claude session, open the Google Drive connector and paste the client folder link. Dr. Otero reads all documents live — no copy-pasting needed. Full live analysis in real time.
6
Consistent naming convention
Always: [ClientInitials]_[DocType]_[YYYYMMDD]
Example: TCCA_Assessment_20260609.pdf
